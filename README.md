# suhas102.github.io

Personal portfolio for Suhas Suresha. Static HTML, CSS and JavaScript, no build step for the main site.

- `index.html`: GitHub-profile-style home page: sidebar, tabs (Overview, Repositories, Interactive demos, Experience)
- `assets/css/site.css` (components) and `gh.css` (GitHub-profile layout), `assets/js/*.js`: styles and scripts
- `case-studies/*.html`: generated by `python3 tools/build_case_studies.py` (needs `markdown`; set `RISK_SRC` to the risk-portfolio folder)
- `index-academic.html`: older academic-style page, kept as is

Preview: `python3 -m http.server 8000`, then open http://localhost:8000.
To add a project: add a row in the Work section of `index.html` and a page entry in `tools/build_case_studies.py`.
