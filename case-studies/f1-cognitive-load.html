The question

Telemetry-derived measures are often used as proxies for how hard a driver is working mentally. A proxy is only useful if it measures that, and not something that varies with the track, the car or the driver.

Approach

I built a confound-controlled analysis using pandas and scikit-learn, with logistic regression, random forest and XGBoost, and used SHAP to see which signals drove predictions. Data covered 61 race weekends, 28 drivers and over 65,000 laps.

Result

XGBoost reached a ROC-AUC of 0.740. The model was delivered as a queryable reporting tool with command-line and Tkinter interfaces so results can be explored without code.

What it shows about my method

I treat a proxy as a hypothesis to test. Controlling for confounds before trusting a signal is the same discipline I apply to model monitoring and evaluation.
